# Alien Invasion

A game made in Python where the player controls a ship at the bottom of the screen and shoots a fleet of aliens.

## What I built
- A ship the player moves left and right
- Bullets the ship can fire at the aliens
- A fleet of aliens that moves across the screen
- A scoreboard that keeps track of the score
  
## Built with
Python, Pygame

## How to run it
1. Install Pygame: pip install pygame
2. Run the game: python alien_invasion.py
